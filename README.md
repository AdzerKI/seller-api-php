# opotopo/seller-api

Клиент Seller API площадки ОПОТОПО на PHP поверх любого PSR-18 HTTP-клиента: синхронизация позиций каталога, загрузка файлов, приём вебхуков покупок и выдача данных покупок.

```bash
composer require opotopo/seller-api
```

Руководство — https://opotopo.com/knowledge/developers/klient-na-php
